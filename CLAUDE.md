# Word Bots

Kids' reading/spelling/maths battle game, built as an offline PWA for an Android tablet. Full agreed plan: [docs/PLAN.md](docs/PLAN.md).

## Rules
- **British English spelling** in all user-facing text and content. Check this on every content change.
- Every fact in the content must have a `source` URL from the trusted-source list in the plan. Don't add facts without verifying them.
- No personal info (player's name, photos) in the repo — the repo is public.
- Never embed API keys in the app. Any Gemini TTS audio is pre-generated offline and shipped as static files.
- Original art only; no copyrighted game imagery.
- Agile: keep the MVP small, ship playable increments.
